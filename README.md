# User Account Password Generator

This Python script reads user data from `user_in.csv`, generates secure passwords for each user, and saves the results (username + password) to `user_out.csv`.  
It uses Python’s `secrets` and `csv` modules to automate password creation and user account management.

## Features:
- Reads user data from `user_in.csv`.
- Generates random passwords for users.
- Outputs results to `user_out.csv`.

## Tech Stack:
- Python 3.x
- `secrets` module for secure password generation
- `csv` module for reading and writing CSV files

## Usage:
1. Place the `user_in.csv` file in the project directory.
2. Run the Python script to generate passwords and output the data to `user_out.csv`.
